## Workspace ကို ကြည့်ရန် {#layout}

![ညမြို့ပြပုံ ဖွင့်ထားသော Lime။ ဘယ်ဘက်တွင် Tools၊ ညာဘက်တွင် Tool Options နှင့် Layers ရှိသည်။](../../../../assets/workspace.jpg)

ပုံထဲတွင် Lime ၏ Desktop workspace ကို ပြထားသည်။ သုံးနေသောစက်တွင် Panel အရွယ်နှင့် ရွေးထားသော Tool ကွာနိုင်သည်။

- **ဘယ်ဘက် Toolbox:** သုံးမည့် Tool ကို ရွေးပါ။ Foreground နှင့် Background Color swatch များက အပေါ်ဆုံးတွင် ရှိသည်။
- **အလယ် Canvas:** ပုံကို ကြည့်ပြီး ပြင်သည့်နေရာဖြစ်သည်။ ဖွင့်ထားသော Document တစ်ခုစီတွင် Tab ရှိသည်။ Checkerboard က Transparent နေရာကို ပြသည်။ ပုံထဲတွင် ပါသော နောက်ခံ မဟုတ်ပါ။
- **ညာဘက် Tool Options:** လက်ရှိ Tool ၏ Settings ကို ပြင်ပါ။ **?** ပေါ် Pointer တင်ပြီး အသုံးပြုပုံနှင့် Shortcut များ ကြည့်ပါ။ Secondary settings အုပ်စုများကို Header မှ ခေါက်ထားနိုင်သည်။
- **ညာဘက် Layers / Paths:** ပြင်မည့် Layer ကို ရွေးပါ။ Curve များ စီမံရန် **Paths** သို့ ပြောင်းပါ။ အခြား Layers မြင်နေရသော်လည်း Pixel ပြင်ဆင်မှုအများစုက Active layer ကိုသာ သက်ရောက်သည်။
- **Application menus:** Open၊ Save၊ Export၊ Undo စသည်တို့ကို Menu တွင် ရှာပါ။ Canvas အပေါ်တွင် Editing toolbar မရှိပါ။

## Canvas အတွက် နေရာချဲ့ရန် {#steps}

1. Docked panels ကို အရွယ်ပြင်ပါ သို့မဟုတ် Toolbox ကို ခေါက်ပါ။
2. **View → Toggle Right Sidebar**၊ Sidebar header ခလုတ် သို့မဟုတ် **Cmd/Ctrl+Shift+L** ဖြင့် Tool Options နှင့် Layers/Paths ကို အတူခေါက်ပါ။
3. Compact sidebar အပေါ်ဆုံး ခလုတ်ဖြင့် ပြန်ချဲ့ပါ။ Drag လုပ်နေစဉ် ခေါက်မရသဖြင့် အရင် အဆုံးသတ်ပါ။ ဆွဲခြင်းရပ်ထားသော Transform preview ရှိစဉ် ခေါက်နိုင်သည်။
4. **Space** ကို ဖိထားပြီး ဆွဲကာ Pan လုပ်ပါ။ Pixel မပြောင်းဘဲ ချဲ့ကြည့်ရန် **Zoom** ကို သုံးပါ။

Panel ခေါက်ထားမှုကို Lime က မှတ်ထားသည်။ Tab တစ်ခုစီက Zoom နှင့် Pan ကို သီးခြား မှတ်ထားသည်။ Sidebar ခေါက်လည်း ရွေးထားသော Layers/Paths tab နှင့် Draft များ မပျောက်ပါ။

Compact sidebar ၏ အကျယ်သည် ခေါက်ထားသော Toolbox နှင့် တူသည်။ အပေါ်တွင် အဓိက Tool controls၊ ပိုကြီးသော အလယ်ပိုင်းတွင် Layer thumbnails၊ အောက်တွင် Path blocks ရှိသည်။ အပိုင်းတစ်ခုစီကို Scrollbar မမြင်ရဘဲ သီးခြား Scroll လုပ်နိုင်သည်။ အစွန်းရှိ အရိပ်ပါးပါးက ဆက်ကြည့်စရာ ရှိကြောင်း ပြသည်။ Crop၊ Gradient နှင့် Transform preview ကို Apply လုပ်ရန် Canvas ပေါ်တွင် **Return**၊ Cancel လုပ်ရန် **Escape** နှိပ်ပါ။ Numeric field ပြင်နေစဉ် ထို Key များက Field ကို အရင် အပြီးသတ် သို့မဟုတ် မူလတန်ဖိုးသို့ ပြန်ထားပေးသည်။ Options အားလုံးဖွင့်ရန် လက်ရှိ Tool header ကို နှိပ်ပါ။ Move တွင် Horizontal Center နှင့် Vertical Center ခလုတ်နှစ်ခုကို အပေါ်အောက် စီထားသည်။ ထိုခလုတ်များဖြင့် Layer ကို သက်ဆိုင်ရာ ဝင်ရိုးတစ်ခုစီအလိုက် Canvas အလယ်သို့ ရွှေ့ပါ။ ပုံမဖွင့်ထားစဉ် Tools အားလုံး၏ Compact controls ကို ဖျောက်ထားပြီး လက်ရှိ Tool header ကိုသာ ပြသည်။ Flip ၏ **H/V** ခလုတ်ဖြင့် Horizontal/Vertical ပြောင်းပါ။ Gradient ၏ Color ခလုတ်တစ်ခုတည်းကို နှိပ်ပြီး **F→B** (Foreground မှ Background သို့) နှင့် **F→A** (Foreground မှ Transparent သို့) ပြောင်းနိုင်သည်။ Text တွင် Size နှင့် နှိပ်ပြီး Color ရွေးနိုင်သော Swatch ရှိသည်။

နောက်ဆုံး Layer thumbnail ပြီးနောက်ရှိ **+** ခလုတ်ဖြင့် New Layer dialog ဖွင့်ပါ။ ထိုခလုတ်က Layer list နှင့်အတူ Scroll ဖြစ်ပြီး ပုံဖွင့်ထားမှသာ ပေါ်သည်။ Layer thumbnail ကို နှိပ်ပြီး ရွေးပါ။ Double-click ဖြင့် နာမည်ပြောင်းပါ၊ Right-click ဖြင့် Context menu ဖွင့်ပါ၊ ဆွဲပြီး အစီအစဉ်ပြောင်းပါ။ Pointer တင်လျှင် နာမည်နှင့် အခြေအနေကို ကြည့်နိုင်သည်။ Active သို့မဟုတ် Hidden layer တွင် Eye ခလုတ် အမြဲပေါ်ပြီး အခြား Thumbnail များတွင် Pointer တင်မှ ပေါ်သည်။ Path block ၏ နေရာလွတ်ကို နှိပ်ပြီး ရွေးပါ။ Eye ဖြင့် ပြ/ဖျောက်လျှင် ရွေးထားသော Path မပြောင်းပါ။ Pointer တင်လျှင် Path နံပါတ်နှင့် Anchor အရေအတွက်ကို ကြည့်နိုင်သည်။ Compact နှင့် Expanded panels ၏ Scroll နေရာများကို သီးခြား မှတ်ထားသည်။

Compact ခလုတ်များကို **Tab/Shift+Tab** ဖြင့် Focus ရွှေ့ပြီး **Return/Space** ဖြင့် အသုံးပြုပါ။ Numeric field ပေါ် Focus ရှိစဉ် Return/Space ဖြင့် စပြင်နိုင်သည်။ ပြင်နေစဉ် Return က အပြီးသတ်ပြီး Escape က မူလတန်ဖိုး ပြန်ထားပေးသည်။ စာသားတိုဖြတ်ထားသော တန်ဖိုးပေါ် Pointer တင်ပြီး အပြည့်အစုံ ကြည့်နိုင်သည်။ ရှည်သော Numeric တန်ဖိုး ပြင်လျှင် Caret နေရာသို့ Scroll လိုက်ပေးသည်။ Path Tool ၏ **Stroke** ခလုတ်က လက်ရှိ Stroke settings ဖြင့် ချက်ချင်း ပုံဆွဲပေးသည်။ Layer သို့မဟုတ် Path visibility မပြောင်းမီ Canvas preview ကို Apply သို့မဟုတ် Cancel လုပ်ပါ။

## Menu သုံးရန် {#menus}

macOS တွင် System menu bar၊ Windows တွင် Native window menu ကို သုံးသည်။ Linux တွင် Window အတွင်း Menu bar ရှိပြီး **F10** ဖြင့် Focus လုပ်နိုင်သည်။ **Alt** နှင့် မျဉ်းသားထားသော စာလုံးကို နှိပ်လျှင် ထို Menu ဖွင့်သည်။ Arrow keys ဖြင့် ရွှေ့ပြီး **Enter** ဖြင့် ရွေးပါ။ Submenu က မူရင်း Menu ၏ ဘေးတွင် ပွင့်သည်။ **Right** သို့မဟုတ် **Enter** က Submenu ဖွင့်ပြီး **Left** သို့မဟုတ် **Escape** က တစ်ဆင့်ပြန်ပိတ်သည်။ အပေါ်ဆုံးအဆင့်တွင် **Escape** က Menu အားလုံးပိတ်သည်။
