Layer၊ Selection၊ ပုံဆွဲခြင်း၊ Text နှင့် ပုံပြင်ဆင်မှုများအတွက် လက်တွေ့လမ်းညွှန်များ။

ပထမဆုံး ပုံပြင်ရန် ↗Lime ရယူရန် ↓Workspace ကို လေ့လာရန် →

ပုံပြင်ဆင်နည်းများ

ပုံကို Crop လုပ်ရန် ↗ပုံထဲမှ သိမ်းထားမည့် အပိုင်းကို ရွေးပါ။နောက်ခံ ဖယ်ရှားရန် ↗လိုသည့်အရာကို ရွေး၍ နောက်ခံကို ဖယ်ရှားပါ။ပုံများ ပေါင်းစပ်ရန် ↗Layer များဖြင့် ပုံတစ်ပုံအဖြစ် ပေါင်းစပ်ပါ။Text နှင့် Outline ထည့်ရန် ↗Text ကို ဆက်ပြင်နိုင်သည့်အတိုင်း Effects ထည့်ပါ။ပုံကို Resize လုပ်ရန် ↗ပုံကို Scale လုပ်မလား၊ Canvas size ပြောင်းမလား ရွေးပါ။Save နှင့် Export လုပ်ရန် ↗ပြန်ပြင်နိုင်သည့် Project ကို Save လုပ်ပြီး မျှဝေရန် ပုံကို Export လုပ်ပါ။

Canvas အတွက် နေရာပိုရစေရန်
